# QKD Panel Web

Frontend Vite + React 18 + TypeScript para el panel local de `qiskit-qkd`.

```powershell
npm.cmd install
npm.cmd run dev
```

El servidor de desarrollo escucha en `http://127.0.0.1:5173` y reenvia `/api`
a `http://127.0.0.1:8000`.

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run build
```
